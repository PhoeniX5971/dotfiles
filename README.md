# My Dotfiles

A configuration repository for my personal setup.

## Purpose

Having those dotfiles in a git repository allows me to easily keep
track of changes and deploy them on new machines.

## Disclaimer

This means that I **DID NOT WRITE ALL THESE FILES BY MYSELF**.

> Some of them are made by me while the others are taken from the internet.
> Also since this was originally using the ml4w hyprland, most of the stuff
> in scripts directory are not used now, but I cannot be bothered to clean them.
